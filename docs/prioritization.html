Suggestion

Build one game loop with a switch for two modes: constrained (the LLM picks from the legal-move list) and free (the LLM says any move, and the game counts how long it stays legal).

Stories 3 and 6 describe the same constrained mode, and 2 and 7 the same free mode, so building one switch covers four stories. The free-mode legal-move count is your headline metric for the article and gives you a Levy-style hook.

Leave Elo, RAG and prompt injection for later. You can only compute Elo once LLM-vs-engine games run unattended, and small local models take several seconds per move.
